🤖 OER Chatbot UI Demo

This is a standalone demo of the chatbot popup component. The popup appears in the bottom-right corner of your screen. Click the header to minimize/maximize it.

To integrate into your DSpace UI:

1. The chatbot component is already created in: src/app/chatbot-popup/

2. Mount it in your root component or theme override

3. Configure the API endpoint in your environment settings

4. Update the chatbot service to call your backend API
